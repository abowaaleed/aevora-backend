# ايفورا (Aevora) — Zero-Cost Web App

مساعد ذكي يعمل **بالكامل داخل متصفح المستخدم** بمفاتيحه الخاصة (BYOK) — بلا أي خادم خلفي،
بلا تخزين سحابي مدفوع، وبلا بطء. كل بيانات المستخدم تبقى على جهازه.

## العمارة (Zero-Cost Architecture)

| الميزة | التنفيذ |
| --- | --- |
| الذكاء الاصطناعي (محادثة + مساعد شخصي) | اتصال مباشر بـ Gemini API (`generativelanguage.googleapis.com`) من المتصفح بمفتاح المستخدم |
| التعرف على الصوت (STT) | اتصال مباشر بـ Groq Whisper (`api.groq.com`) من المتصفح بمفتاح المستخدم |
| نطق النص (TTS) | Web Speech API المدمج في المتصفح — مجاني، عربي وإنجليزي، بلا خادم |
| الملفات (PDF/TXT) | قراءة واستخراج النصوص محلياً في المتصفح (syncfusion_flutter_pdf) |
| البحث في المستندات (RAG) | متجهات تُحسب محلياً (Hashing TF) + تشابه جيب التمام داخل المتصفح |
| التخزين | IndexedDB (idb_shim): ملفات، ذكريات، مهام، محادثات، عدّادات يومية |
| العدّادات اليومية | محفوظة بمفتاح تاريخ اليوم في IndexedDB — لا تتصفّر عند الإغلاق |
| الاستضافة | Static Files / PWA على أي استضافة مجانية (GitHub Pages / Cloudflare Pages / Vercel) |

## تشغيل محلي

```bash
cd aevora_web
flutter pub get
flutter run -d chrome
```

ثم أدخل مفاتيحك في شاشة الإعداد الأولى. لا حاجة لأي خادم.

## البناء والنشر

```bash
cd aevora_web
flutter build web --base-href=/aevora-backend/
```

انشر محتويات `build/web` على GitHub Pages (أو أي استضافة ثابتة).

> المجلد `backend/` قديم (كان يعمل بالخادم الوسيط) ولم يعد التطبيق يستخدمه.

## الخصوصية

- المفاتيح تُحفظ في localStorage على المتصفح ولا تُرسل إلا إلى مزودها مباشرة.
- الملفات والذكريات والمحادثات محفوظة في IndexedDB على الجهاز نفسه ولا تغادره أبداً.
- البيانات مرتبطة بالمتصفح/الجهاز (المقصود: الخصوصية الكاملة). لمسح كل شيء استخدم
  «تسجيل الخروج» ثم امسح بيانات الموقع من المتصفح.
