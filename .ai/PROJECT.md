# Project Name
AI Companion

# Mission
Build a completely local AI companion that can run without cloud APIs.
The first skill will be an English Teacher.
The architecture must support many future skills.

# First Release Goals
- Natural voice conversation
- English learning
- Long-term memory
- Personality
- Offline AI using Ollama first
- Future migration to llama.cpp

# Technologies
- Flutter
- Python (FastAPI)
- Ollama
- SQLite
- Future support for llama.cpp

# Design Philosophy
- Modular architecture
- Offline-first
- Clean code
- Easy to extend
- AI-first

# Non Goals
- No Firebase
- No cloud dependency
- No paid API required for the application to function
